# HireScope AI



An intelligent semantic resume analysis and career recommendation system using NLP and machine learning.



##  Overview



HireScope AI analyzes resumes and compares them with job roles using semantic similarity and skill matching.



It helps candidates understand how well their resume matches a role and identifies relevant skills and career opportunities.



##  Features



-  Candidate and Recruiter authentication

-  Resume upload and analysis

-  Semantic similarity using Sentence Transformers

-  Job-role recommendation

-  Resume-job matching score

-  Matched skills identification

-  Missing skills identification

-  Resume analysis history

-  Recruiter-side multi-resume ranking

-  Custom Job Description analysis

-  Printable analysis report



##  Tech Stack



- **Backend:** Python, Flask

- **Frontend:** HTML, CSS, Bootstrap 5

- **Database:** SQLite, Flask-SQLAlchemy

- **NLP:** Sentence Transformers

- **Machine Learning:** Semantic Similarity

- **Data Processing:** Pandas

- **PDF Processing:** PyPDF2

- **Visualization:** Chart.js



##  Matching Approach



HireScope AI calculates the overall matching score using:



**Overall Score = 60% Semantic Similarity + 40% Skill Match**



Semantic similarity is generated using the `all-MiniLM-L6-v2` Sentence Transformer model.
